# Digital Clock & Alarm System (C++)

## 📌 Overview
A console-based digital clock application developed in C++ that allows users to set the current time, display it in real-time, and optionally activate an alarm.  
This project was created as an early academic exercise to strengthen logical thinking and time-based programming concepts.

## 🛠 Features
- Real-time digital clock display
- Supports AM / PM format
- Alarm functionality with sound alert
- Input validation for time settings
- Console-based user interface

## 💻 Technologies Used
- C++
- Standard Input/Output
- Windows API (`Sleep()` for timing)

## 📂 Project Type
Academic / Early Learning Project

## ⚠️ Notes
- Originally developed during early university studies.
- Code structure reflects foundational programming practices.
- Designed for Windows environments (uses `<windows.h>`).
