# C++ Console Systems (Fundamentals)

This repository contains a collection of console-based C++ projects
developed during my early academic years.

## Purpose
These projects demonstrate:
- Strong programming fundamentals
- Logical thinking and problem-solving
- Control flow, functions, and modular structure
- Working without AI-assisted tools

> Note: These projects were built before the use of AI tools and reflect
> my independent thinking and learning process at that stage.

## Included Systems
- Car Rental System
- Restaurant Ordering System
- Library Management System
- Digital Clock

Each project has its own folder with a brief explanation.
