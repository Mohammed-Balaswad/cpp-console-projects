## 🍽️ Restaurant Ordering System (C++)

### Project Overview
A console-based restaurant ordering system developed using C++.
The program allows users to browse menu categories, place orders, calculate total cost, and process payment.

### Key Features
- Menu-based navigation (Appetizers, Main Dishes, Beverages, Desserts)
- Order quantity handling
- Real-time total price calculation
- Cash payment and change calculation
- User-friendly console interface

### Purpose
This project was developed during my early university studies to strengthen my understanding of:
- Control structures (loops, switch-case)
- User input handling
- Basic program flow design
- Problem-solving using C++

### Notes
- This project reflects my foundational programming skills.
- The implementation focuses on logic clarity rather than advanced design patterns.
- Future improvements could include modular functions and data structures.
